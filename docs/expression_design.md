### 2.2 しぐさ(手)は感情から独立した軸にする

感情プリセットのデフォ手に加え、台本JSONにオプション `gesture` を持たせる(なければ感情のデフォ):

| gesture | ずんだもんの手 | めたんの手 | 意図 |
|---|---|---|---|
| `point` | 指 | 指 | 解説の定番・画面のカードを示す |
| `raise` | 手を挙げる+手を挙げる | 手をかざす+抱える | 発表・宣言 |
| `think` | 考える+口元 | 口元に指+普通 | 思考 |
| `akimbo` | 腰+腰 | 普通+抱える | ツッコミ構え |
| `snack` | 基本+基本(枝豆) | まんじゅう+まんじゅう袋 | 食べてる・金欠ネタ |
| `whisper` | ひそひそ | ひそひそ | 内緒話 |
| `mic` | マイク+基本 | マイク+マイク | 導入・結び・インタビュー風 |

ランダムバリエーション: StockSeeker 実績の重み(デフォ70% / バリアント30%)を踏襲し、同じ感情が続いても腕を多少変えて単調さを避ける。

### 2.3 反応表情(話していない側)

聞き手が棒立ちだと動画が死ぬ。**話者の感情に応じて聞き手側も表情を変える**(既存のシーン切替機構でそのまま実装可):

| 話者の感情 | 聞き手の反応 |
|---|---|
| happy/excited | happy(釣られて笑う) |
| surprised | surprised |
| angry(ツッコまれた側) | fail または cry |
| angry(第三者) | smug(ニヤニヤ傍観) |
| sad | sad or think(心配) |
| fail | surprised→smug(次行で) |
| whisper | whisper(乗っかる) |
| think | neutral(じっと聞く) |

### 2.4 台本JSON拡張(案)

```json
{
  "title": "...",
  "lines": [
    {"speaker": "shikoku_metan", "text": "...", "emotion": "angry", "gesture": "akimbo"},
    {"speaker": "zundamon", "text": "...", "emotion": "fail", "gesture": "snack"}
  ]
}
```

- emotion の enum をプロンプトに列挙し、**1セリフ1感情・変化は行頭**(実装がシンプル+同期機構そのまま)
- gesture は省略可。LLMが付けすぎたら検証側で間引く(2行に1回まで等)
- 「解説の基本は neutral+point。happy/surprised は引き、angry/fail は間隔を空ける」をプロンプトに明記し、感情のインフレを防ぐ

### レシピC: 口パク(YMM4標準・滴了庵日録)

四国めたんの口パクは「*ほほえみ」→「*わあー」→「*ほほえみ」の往復。つまり**closed 口は「ほほえみ」系**を使うのが定番(△より柔らかい)。ずんだもんは「*ほあー」開き系。

### レシピD: 立ち絵表情の設計理論(佐藤翼「どんな表情の立ち絵が必要か」)

- 基本7+1表情(通常/喜/怒/哀/驚/照れ/眠 +  笑顔ベース)×シチュエーション4×パーツ3
- 眉・目・口を**独立パーツ**として扱い「困り眉+笑い口=困り笑い」のような合成を想定
- 汗・涙は**量の差分**(1個/複数)で強弱を作る → 本PSDの汗1-3がまさにこれ
